Being told is not the same as being safe.

CircleCI went down for nearly two hours in March 2022 because an API endpoint they depended on moved. GitHub had announced the change 770 days earlier.[1] Somebody still had to map a prose announcement onto their own call sites, and nobody did — because that job belongs to a machine.

Precision is the product.

The first version reported 86 findings on a real 1,200-dependency repository, and roughly a quarter were real — refund was matching inside refunded. Every artifact kind now matches only in the shape it takes when actually sent to a provider. A tool that is wrong three times out of four gets muted, then deleted.

Rules that don't bend.

Every fact cites the provider

A finding links to the provider's own deprecations page or spec diff.[3] Verify it in one click. You should not have to trust us — no language model sits anywhere in the detection or fix path.

Severity is computed against today

"Deprecated, retires 2026-10-23" is a countdown, not a footnote. Findings sort by time left: breaks in 88 days before, DIED 935 days ago after. No dependency tool has a field for time remaining.

It refuses to guess

Only replacements the provider itself named are applied, inside the quoting your code already uses. Anything needing judgment is reported and left alone, out loud.
